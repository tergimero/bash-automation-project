# Tasks Automation Using Bash Scripting

## Overview
This project demonstrates Bash scripting for DevOps
automation, system monitoring, reusable functions,
and defensive programming.

## Technologies
- Bash
- macOS Terminal
- Git and GitHub

## Project Scripts

### 1. create_files.sh
Automates directory and file creation using mkdir,
touch, timestamps, and conditional checks.

### 2. health_monitor.sh
Monitors disk usage, memory, and running processes.
Reports system health and uses exit codes.

### 3. functions.sh
Contains reusable functions for logging, disk
monitoring, memory information, and processes.

### 4. safe_automation.sh
Validates user input, handles errors, uses strict
Bash settings, and performs cleanup with traps.
